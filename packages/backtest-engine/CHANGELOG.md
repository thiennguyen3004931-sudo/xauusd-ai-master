# Changelog

- Added event-driven candle replay.
- Added explicit look-ahead protection.
- Added next-bar and planned-price entry modes.
- Added commission, spread and slippage models.

- Added break-even and ATR trailing-stop simulation.
- Added conservative, optimistic and OHLC-path intrabar policies.
- Added equity, drawdown and monthly-return curves.
- Added full performance metrics.

- Added rolling and anchored walk-forward windows.
- Added Markdown, CSV and JSON report formatting.
- Added Vitest coverage and strict TypeScript configuration.
